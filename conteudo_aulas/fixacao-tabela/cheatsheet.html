Tabela HTML POO / Classe localStorage Botões / Ações
Tabela

thead / tbody / tfoot

Use quando: thead = rótulo fixo da coluna. tbody = dados, é o único que o JS apaga e recria. tfoot = total/resumo, fica fora do loop de dados.

<table>
  <thead>...</thead>   // fixo
  <tbody></tbody>      // JS enche aqui
  <tfoot>...</tfoot>   // total
</table>
Tabela

tr vs td vs th

Use quando: precisar lembrar quem contém quem. tr é a linha (o trilho); td/th são as células dentro dela. td nunca existe sozinho.

<tr>              // 1 objeto = 1 tr
  <td>valor</td>  // 1 campo = 1 td
</tr>

th = rótulo (no thead)
td = dado (no tbody/tfoot)
Tabela

Redesenhar o tbody

Use quando: os dados mudaram (removeu, adicionou, editou) e a tabela precisa refletir isso na tela.

function desenhar(lista) {
  const tbody = document
    .querySelector('tbody');
  tbody.replaceChildren(); // limpa
  lista.forEach(item =>
    tbody.append(criarLinha(item)));
}
POO

Atributo privado

Use quando: quiser proteger um dado da classe para que só ela possa alterá-lo diretamente.

class Produto {
  #id = 0;
  #nome = '';
}
// fora da classe: produto.#id → ERRO
POO

Constructor

Use quando: for criar uma instância nova com new. Atribua sem # para passar pelo set.

constructor(id = 0, nome = '') {
  this.id = id;     // chama o set
  this.nome = nome; // chama o set
}
POO

get / set

Use quando: precisar ler ou escrever um atributo privado a partir de fora da classe.

get nome() { return this.#nome; }
set nome(v) { this.#nome = v; }

// uso: produto.nome / produto.nome = 'x'
localStorage

Salvar

Use quando: o array de dados mudou e precisa sobreviver ao F5. Só aceita string, por isso o stringify.

localStorage.setItem(
  'produtos',
  JSON.stringify(listaProdutos)
);
localStorage

Carregar

Use quando: a página abre e precisa recuperar os dados salvos. Trate o caso de "nunca salvou".

const txt = localStorage.getItem('produtos');
const lista = txt === null
  ? []
  : JSON.parse(txt);
localStorage

Cuidado: perde a classe

Use quando: os dados carregados precisam voltar a ser instância de Produto (com get/set), não objeto solto.

// JSON.parse devolve objeto "sem classe"
lista.map(p =>
  new Produto(p.id, p.nome, p.preco));
Botão

Criar + ouvir clique

Use quando: cada linha da tabela precisar de uma ação própria, como remover.

const btn = document.createElement('button');
btn.innerText = '🗑️';
btn.addEventListener('click',
  () => remover(produto));
Botão

As 3 etapas de toda ação

Use sempre: remover, cadastrar ou alterar seguem esta mesma ordem. Esquecer uma etapa é o bug mais comum.

1. mexe no ARRAY
2. redesenha o TBODY
3. salva no localStorage
Botão

dialog (modal)

Use quando: precisar de um formulário para cadastrar ou editar sem sair da página.

dialog.showModal();  // abre
dialog.close();      // fecha

// no submit do form:
event.preventDefault(); // não recarrega
